# Warcraft Mod для CS2

Мод в духе классического Warcraft-мода для Counter-Strike 2: игрок выбирает расу, получает опыт
за убийства, качает уровни и распределяет очки в пассивные, активные и ультимативные способности.

Написан на C# для **CounterStrikeSharp** (поверх Metamod:Source 2). 13 рас, 16 уровней,
прогресс хранится по SteamID отдельно для каждой расы.

[English README](README.md)

**Посмотреть вживую:** `connect 45.95.31.2:27015` — там мод работает на живом сервере.

---

## Что умеет

- **Система рас с автоматической регистрацией.** Новый класс-наследник `Race` подхватывается сам —
  ни реестра править, ни зависимостей прописывать.
- **16 уровней, по очку навыка за уровень.** У каждой расы ровно 4 способности (2 пассивки,
  активка, ультимейт) по 4 ранга — очки всегда сходятся.
- **Прогресс сохраняется отдельно по каждой расе.** Смена расы не стирает старую прокачку.
- **Автораспределение очков** для тех, кто не хочет думать над билдом.
- **Правка урона до его применения** — крит, уклонение, блок, снижение урона, вампиризм.
- **Игровые меню** выбора расы, прокачки и админских действий.
- **Голосование за карту** в конце раунда из настраиваемого пула.
- **Донатные расы**, выдаются командой — если сервер платный.

## Команды в игре

| Команда | Что делает |
|---|---|
| `!race` | Меню выбора расы |
| `!skills` | Распределить очки навыков |
| `!ability` | Применить активную способность |
| `!ult` | Применить ультимейт |
| `!wcinfo` | Описание вашей расы и текущих рангов |
| `!resetskills` | Сбросить распределение очков |
| `!wchelp` | Список команд |

Удобные бинды в консоли клиента:

```bash
bind mouse4 css_ability; bind mouse5 css_ult
```

Админские команды (`css_wcgrant`, баны, сбросы) перечисляет `css_wchelp` в консоли сервера.

## Установка на сервер

Если вы никогда этого не делали — читайте подряд, шаги идут в том порядке, в котором их надо
выполнять. Всё вместе занимает час-полтора, и большая часть этого времени — скачивание.

**Из чего собран сервер.** Четыре слоя, каждый стоит поверх предыдущего:

```
CS2 Dedicated Server           сам игровой сервер от Valve
  └── Metamod:Source           подсовывает движку сторонний код
      └── CounterStrikeSharp   даёт плагинам писать на C#
          └── WarcraftMod      этот мод
```

Пропустить нельзя ни один: без Metamod не запустится CounterStrikeSharp, без него — мод.

> ### Не ставьте это в свою игровую копию CS2
>
> Сервер — **отдельная установка**, которую вы сейчас скачаете через SteamCMD. Она никак не
> связана с игрой, в которую вы играете. Если поставить Metamod в игровой клиент, изменённый
> `gameinfo.gi` начнёт грузить мод и на обычных серверах — **это риск бана VAC.**

---

### Шаг 1. Поставить SteamCMD

SteamCMD — консольная качалка Valve, через неё скачивается сам сервер.

1. Скачайте архив под свою систему с [developer.valvesoftware.com/wiki/SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD).
2. Распакуйте в отдельную папку, например `C:\steamcmd`. **Не в «Загрузки» и не на рабочий стол** —
   SteamCMD распакует рядом с собой ещё пару сотен мегабайт.

### Шаг 2. Скачать сервер CS2

Одна команда. Steam-аккаунт не нужен, сервер раздаётся анонимно:

```bash
C:\steamcmd\steamcmd.exe +force_install_dir C:\cs2server +login anonymous +app_update 730 validate +quit
```

Скачается около 40 ГБ — от получаса на быстром канале до нескольких часов.

**Чему тут нельзя верить:** размер папки `C:\cs2server` вырастет до полного почти сразу, Steam
резервирует место под все файлы заранее. Настоящий признак того, что процесс идёт, — строки
`Update state ... progress:` в окне SteamCMD. Появляются — всё в порядке, просто ждите.

Когда закончится, должен существовать файл `C:\cs2server\game\bin\win64\cs2.exe`.

### Шаг 3. Поставить Metamod:Source

1. Откройте [страницу загрузок Metamod:Source](https://www.sourcemm.net/downloads.php).
2. Возьмите **ветку `dev`, версию 2.x**, архив под свою платформу (Windows или Linux).
   Стабильная ветка 1.x с CS2 не работает — это самая частая ошибка на этом шаге.
3. Распакуйте архив так, чтобы папка `addons` из него легла в `C:\cs2server\game\csgo\`.
   Должен получиться путь `C:\cs2server\game\csgo\addons\metamod\`.
4. Откройте `C:\cs2server\game\csgo\gameinfo.gi` в текстовом редакторе, найдите блок
   `SearchPaths` и добавьте строку `Game csgo/addons/metamod` **выше** строки `Game csgo`:

```
SearchPaths
{
    Game_LowViolence    csgo_lv
    Game                csgo/addons/metamod
    Game                csgo
    Game                csgo_imported
    ...
```

> **Осторожно с сохранением этого файла.** `gameinfo.gi` должен остаться в UTF-8 **без BOM**.
> Блокнот и `Set-Content -Encoding utf8` в PowerShell 5.1 дописывают BOM — после этого движок
> перестаёт разбирать файл и сервер не поднимется. Безопасно: Notepad++, VS Code, любой
> редактор с явным выбором «UTF-8 без BOM».

### Шаг 4. Поставить CounterStrikeSharp

1. Откройте [релизы CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp/releases).
2. Возьмите сборку **`with-runtime`** — она несёт .NET внутри, ставить его отдельно не нужно.
3. **Внимательно выберите платформу.** Архивы называются похоже, и скачать linux-сборку на
   Windows очень легко. Ломается всё молча, а чинится только распаковкой правильной сборки
   поверх — подробности ниже, в «Если что-то не работает».
4. Распакуйте так же, как Metamod: папка `addons` из архива ложится в `C:\cs2server\game\csgo\`.
   Должен получиться путь `C:\cs2server\game\csgo\addons\counterstrikesharp\`.

Шаги 3 и 4 на Windows делает скрипт из этого репозитория — распакует оба архива и сам пропишет
Metamod в `gameinfo.gi` без BOM:

```bash
.\tools\install-server-addons.ps1 -ServerRoot C:\cs2server -MetamodZip .\metamod.zip -CssZip .\css.zip
```

Скрипт можно запускать повторно: дублей в `gameinfo.gi` он не создаёт.

### Шаг 5. Поставить сам мод

Нужен собранный `WarcraftMod.dll`. Собрать из исходников (понадобится
[.NET SDK 10](https://dotnet.microsoft.com/download)):

```bash
dotnet build -c Release
```

Готовые файлы появятся в `src\WarcraftMod\bin\Release\net10.0\`. Скопируйте **всё содержимое**
этой папки в:

```
C:\cs2server\game\csgo\addons\counterstrikesharp\plugins\WarcraftMod\
```

Папку `WarcraftMod` создайте сами, если её нет. На Windows оба действия делает скрипт:

```bash
.\tools\deploy-plugin.ps1 -ServerRoot C:\cs2server
```

Он соберёт мод и скопирует файлы, не тронув `warcraft_config.json` и `warcraft_players.json` —
настройки и прогресс игроков переживают обновление мода.

### Шаг 6. Запустить и проверить

Сначала локально, без выхода в интернет:

```bash
cd C:\cs2server\game\bin\win64
cs2.exe -dedicated -console -condebug -port 27015 +sv_lan 1 +map de_dust2 +maxplayers 12
```

**Три проверки по порядку.** Если не сходится первая, остальные смотреть бесполезно:

| Что проверяем | Где смотреть | Что должно быть |
|---|---|---|
| 1. Поднялся ли CounterStrikeSharp | `game\csgo\addons\counterstrikesharp\logs\` | Файл с **сегодняшней** датой. Он пишется при каждом старте: нет файла — CSSharp не загрузился |
| 2. Видит ли он мод | Консоль сервера: `css_plugins list` | В списке есть `WarcraftMod` |
| 3. Работает ли мод в игре | Зайти на сервер и набрать `!race` | Открылось меню выбора расы |

Зайти на свой сервер: в игре открыть консоль (`~`) и набрать `connect 127.0.0.1:27015`.

### Шаг 7. Выпустить сервер в интернет

Пока в команде стоит `+sv_lan 1`, сервер видите только вы. Чтобы он попал в браузер серверов:

1. Получите **GSLT-токен** на [steamcommunity.com/dev/managegameservers](https://steamcommunity.com/dev/managegameservers),
   код игры — `730`.
2. Уберите `+sv_lan 1` и добавьте `+sv_setsteamaccount ВАШ_ТОКЕН`.
3. Пробросьте порт `27015` (TCP и UDP) на роутере, если сервер стоит дома.

**Токен нужен не только для видимости.** Без него сервер не может спросить у Steam, кто к нему
подключился, — мод не получит SteamID и не сможет ни загрузить, ни сохранить прогресс. Со стороны
это выглядит как «мод не работает у игроков», хотя загрузился он нормально.

Токен — это пароль. Не кладите его в репозиторий и не показывайте на скриншотах: передавайте
через переменную окружения или настройки панели хостинга.

### Если что-то не работает

Собрано из того, обо что спотыкались на живом сервере.

| Симптом | Что произошло | Что делать |
|---|---|---|
| Сервер стартовал, но `css_plugins list` отвечает «unknown command» | CounterStrikeSharp не загрузился. **При неудаче он молчит** — ни ошибки в консоли, ни строки в логе Metamod | Проверьте, есть ли сегодняшний файл в `addons\counterstrikesharp\logs\`. Нет — смотрите следующую строку |
| Сегодняшнего лога CSSharp нет | Скачана сборка не под ту платформу: `addons\metamod\counterstrikesharp.vdf` указывает на `bin\linuxsteamrt64\` вместо `bin\win64\`, и в папке `dotnet\` перемешался рантайм двух систем | Распакуйте поверх правильную по платформе сборку `with-runtime`. Лишние `.so` рядом с `.dll` не мешают, Windows их игнорирует |
| Сервер падает сразу при старте | Кириллица в `server.cfg` — например, в `hostname` | Конфиги сервера писать только латиницей |
| Мод работал, а после обновления сервера пропал | `app_update 730 validate` **ничего не чинит, он откатывает**: возвращает заводские `gameinfo.gi` и `cfg\server.cfg`, стирая строку Metamod | Повторите шаг 3 или запустите `install-server-addons.ps1` заново |
| Мод загрузился, но прогресс у игроков не работает | Нет GSLT-токена: сервер не получает SteamID | Шаг 7 |
| Команды мода видит весь чат | Это настройка CounterStrikeSharp, а не мода | В `addons\counterstrikesharp\configs\core.json` перенесите префикс `!` из `PublicChatTrigger` в `SilentChatTrigger`. Файл читается только при старте — нужен перезапуск сервера, `css_plugins reload` его не подхватит |

**Где смотреть логи:**

- Ошибки мода и CounterStrikeSharp — `game\csgo\addons\counterstrikesharp\logs\log-cssharp<дата>.txt`
- Консоль сервера с ключом `-condebug` пишется **не** в `game\csgo\console.log`, как можно
  подумать, а в `game\csgo\addons\metamod\console.log`
- Если лог CSSharp обрывается и через несколько секунд начинается заново со строки
  «CounterStrikeSharp is starting up» — это нативный краш, а не ошибка в C#

## Настройка

При первом запуске плагин создаёт рядом с собой два файла:

- `warcraft_config.json` — опыт, интервал сохранения, список админов, границы карт, приветствия.
  Все ключи с разумными значениями — в [`warcraft_config.example.json`](warcraft_config.example.json).
- `warcraft_players.json` — прогресс игроков. Его надо бэкапить и нельзя коммитить.

Впишите свой SteamID64 в `Admins`, чтобы получить доступ к админскому меню.

## Как добавить свою расу

Создайте файл в `src/WarcraftMod/Races/`, унаследуйтесь от `Race` и опишите способности.
Регистрировать нигде не нужно — реестр найдёт класс сам.

```csharp
public sealed class MyRace : Race
{
    public override string Id => "myrace";       // не менять после релиза: по нему хранится прогресс
    public override string Name => "Моя раса";
    public override string Description => "Что она умеет";

    public override IReadOnlyList<Ability> Abilities { get; } =
    [
        new Ability { Name = "Пассивка", Description = "...", Kind = AbilityKind.Passive },
        new Ability { Name = "Пассивка 2", Description = "...", Kind = AbilityKind.Passive },
        new Ability { Name = "Активка", Description = "...", Kind = AbilityKind.Active, Cooldown = 25f },
        new Ability { Name = "Ульта", Description = "...", Kind = AbilityKind.Ultimate, RequiredLevel = 6, Cooldown = 60f },
    ];

    public override void OnSpawn(WarcraftPlayer player) { }
    public override bool OnActivateAbility(WarcraftPlayer player) => false;
}
```

Правила, о которых легко забыть:

- **Порядок способностей менять нельзя** — ранги хранятся по индексу. Новые дописывайте в конец.
- Сумма `MaxRank` всех способностей должна равняться `XpTable.MaxLevel` (16), иначе очки не сойдутся.
- Ровно одна способность с `Kind = Active` и одна с `Kind = Ultimate` — на них завязаны
  `!ability` и `!ult`.
- Для эффектов пользуйтесь `Effects` (лечение, отбрасывание, невидимость, поиск целей),
  а не лезьте в схему движка напрямую.
- Постоянные бонусы скорости ставьте в `BaseSpeedMultiplier`, временные — в `TempSpeedMultiplier`.

## Структура проекта

```
src/WarcraftMod/
  WarcraftPlugin.cs      точка входа: события, опыт, команды
  Core/
    Race.cs              базовый класс расы
    Ability.cs           описание способности
    WarcraftPlayer.cs    состояние игрока в сессии
    RaceRegistry.cs      автопоиск рас
    XpTable.cs           кривая уровней
    Effects.cs           помощники для способностей
  Races/                 сами расы
  Menus/                 меню выбора расы и прокачки
  Storage/               сохранение прогресса
  Config/                настройки
tools/                   скрипты сборки и установки (PowerShell)
```
